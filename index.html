How it works

Ask a question about the US grid interconnection queue.

8,513 power projects, 1,865 GW in all, are waiting for permission to connect to the US grid. GridQueue answers questions about them with SQL on public data, checks its own numbers, and shows every query it ran.

Try a question

Answers take 30 seconds to 2 minutes. Follow up in plain words, like "now just Texas", or click a bar or county to ask about it.

How GridQueue answers a question

GridQueue is for developers deciding where to build, energy analysts tracking the backlog, and policy and ratepayer groups who need numbers they can source. A team of four agents turns a plain-English question into SQL, checks the result, and explains it.

One question, start to finish

A real run, with the time each step took.

Which counties have the most active queue capacity relative to the generation already operating there?
Planner6.5 sKept it as one question, limited to counties with at least 50 MW already operating, so a tiny base can't make a huge ratio
SQL worker25.5 sRan 4 queries and returned 1,497 counties ranked by queued-to-operating ratio
Verifier17.8 sRan 3 queries of its own to confirm the top ratios and the county count. All checks passed
Writer11.5 sWrote the answer and asked for a county map and a top 10 table, which code drew from the worker's SQL

Answer in 61 secondsDeschutes County, Oregon has about 186 times more capacity queued than operating, followed by Crook County, Oregon and Colorado County, Texas.

Why you can check the numbers

Read-only SQL
Agents can run one SELECT at a time against a read-only database. Category values like region names are checked before a query runs, with a suggestion when one is misspelled.
A second agent checks the work
The Verifier re-runs queries of its own against each finding and can send a worker back for a follow-up.
Every number is traced
Code compares each number in the answer with the query results. A number it can't find goes back to the Writer for one revision. Tables, charts and maps are drawn by code from the SQL.

What the queue is

Before a power plant can connect to the grid, it files an interconnection request and waits while the grid operator studies what upgrades it would need. Most requests never get built.

Request filedThe developer applies and joins the queue
StudiesThe grid operator models the upgrades and their cost
AgreementBoth sides sign an interconnection agreement
OperatingThe project is built and connected

What happened to the 22,348 requests filed from 2000 to 2020

  • 70.9% withdrawn (15,840)
  • 18.8% operating (4,196)
  • 9.0% still active (2,005)
  • 1.4% suspended (303)

Only 3,934 of these requests signed an agreement, and 1,332 of those still withdrew. Across all years, projects that reached operation took a median of 1,309 days, about 3.6 years, from request to operation. That median counts only finished projects, so it understates today's waits.

Where the data comes from

Three public sources are cleaned and joined once, offline, into one 7.9 MB database. The agents query that database, never the raw files.

Sources

  • LBNL Queued Up 2026Every queue request through 2025
  • EIA-860 2025Existing and planned generators
  • LBNL cost studiesUpgrade cost estimates from 5 grid operators and other utilities

Offline build

Fixes broken names and missing values, matches counties to FIPS codes, converts costs to 2024 dollars, and marks which cost estimate is primary when a project was studied more than once.

Tables

  • projects38,201 queue requests
  • eia_generators36,571 generators
  • costs5,485 cost estimates
  • county_summary2,634 counties
  • poi_summary24,524 grid connection points

Tables join on county FIPS code, state and region.

Colors in the charts

Each resource type, region and status keeps one color across every chart, so you can read a new chart at a glance.

What it can't answer

Electricity demand
The queues list generation and storage. Large loads such as data centers aren't in them.
Costs in CAISO and ERCOT
The LBNL cost studies cover PJM, MISO, SPP, NYISO, ISO-NE and some utilities in the West and Southeast.
Final costs
The studies are estimates made while projects wait, not what was finally paid.

When a question needs data like this, GridQueue says so instead of guessing.
